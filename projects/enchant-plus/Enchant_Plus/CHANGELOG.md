# CHANGELOG

## v1.1.4 — 2026-08-22

- 날개 결속 흉갑을 `Q`키로 숫돌 윗면에 올리면 일반 흉갑과 겉날개 1개로 분리하는 역조합을 추가했다.
- 분리 시 결속 제작이 추가한 활공·아이템 이름·희귀도·강제 광택만 제거하고 인챈트, 내구도, 장식, 누적 작업 비용, 사용자 이름·로어와 사용자 지정 데이터는 보존한다.
- 일반 아이템 투척 통계가 해당 플레이어에게만 60틱 로컬 검사 창을 열도록 구현했다. 루트 tick의 전역 엔티티 검색은 추가하지 않았다.
- 공식 서버 회귀 시험에 같은 결속 흉갑을 두 번 검사해도 겉날개가 정확히 1개만 반환되는 복제 방지 검사를 추가했다.
- 한국어 도움말과 문서에서 철퇴 인챈트 표기를 `육중`으로 통일했다. 내부 바닐라 리소스 ID만 코드와 시험 파일에 유지한다.

## v1.1.3 — 2026-08-22

- 사용자 명령과 점수판 objective를 제품명에 맞는 `/trigger ep_help`, `/trigger ep_anvil`, `ep_*`로 교체했다. 기존 `tb_*` 공개 objective는 데이터 버전을 이어받은 뒤 한 번 제거한다.
- 번역 키와 리소스 경로를 `enchant_plus`로 옮기고 도움말을 현재 세 기능만 설명하도록 다시 작성했다. 리소스팩이 없을 때의 기본 문구는 한국어다.
- 저장된 `repair_cost` 원시 NBT가 1 이상인 아이템에만 누적 작업 비용을 표시한다. 비용이 없거나 0인 아이템과 초기화한 아이템에는 `+0레벨` 줄을 만들지 않는다.
- 네더의 별 투척 통계가 해당 플레이어의 4초짜리 로컬 검사 창을 열도록 고쳤다. 매 틱 전역 엔티티 검색 없이, 별과 대상이 실제로 모루 윗면에 놓일 시간을 허용한다.
- 가까운 비용 0 아이템이 있어도 건너뛰고 첫 양수 비용 대상만 처리하며, 초기화 성공 판정도 기본 컴포넌트가 아닌 저장 NBT로 검증한다.
- 공식 26.2 서버에서 소스와 배포 ZIP의 로드, `/reload`, 재시작, `repair_cost 31→없음`, 네더의 별 `2→1`, 기존 구성요소·사용자 로어 보존을 회귀 시험한다.

## v1.1.2 — 2026-08-21

- 배포 ZIP에서 자동시험용 `dev` 함수 3개와 인챈트 적용 아이템 수정자 10개를 완전히 분리했다.
- 자동시험 리소스는 `tools/test_harness`의 별도 보조 데이터팩으로만 서버 시험 중 설치되며 배포되지 않는다.
- 배포 게이트에 동적 인챈트 레지스트리, `dev` 함수와 `dev` 아이템 수정자 0개 검사를 추가했다.
- 런타임 데이터에 `max_level` 정의나 `/enchant` 명령이 없음을 정적 검증해 바닐라 상한 증가 기능의 부재를 고정했다.
- 공식 한국어 번역에서 철퇴 인챈트의 표시명이 `육중`임을 확인하고 문서 표기를 정리했다.

## v1.1.1 — 2026-08-21

- 외부 팩의 인챈트 레지스트리 항목이 26.2에서 `Lifecycle.experimental`로 등록되는 문제를 확인했다.
- 바닐라 인챈트 JSON 오버라이드 12개와 비활성 커스텀 인챈트 호환 정의 4개를 모두 제거했다.
- 인챈트 중복을 `damage`, `armor`, `bow`, `crossbow` 배타 태그와 `sharp_weapon` 아이템 태그만으로 다시 구현했다.
- 공식 26.2 태그 값을 고정 검증해 빈 태그가 보호 4종, 수선·무한, 다중 발사·관통 밖의 조합을 열지 않도록 했다.
- 데이터팩 안의 동적 인챈트 레지스트리 파일 0개를 정적 검증하는 Realm 안전 게이트를 추가했다.
- 제품 버전과 배포 파일명을 v1.1.1 Realm 안전판으로 올렸다.

## v1.1.0 — 2026-08-21

- 제품 범위를 인챈트 중복, 날개 결속 흉갑, 네더의 별 모루 재련 세 가지로 축소했다.
- 폭렬, 균열 사격, 도약, 갈고리, 바람 병, 포션 합성, 줄자, 분필, 분필 나침반, 점프 발판, 수확 낫과 수프 냄비의 획득·실행·틱·도움말 경로를 제거했다.
- 기존 월드의 옛 커스텀 인챈트 아이템을 안전하게 읽기 위해 네 ID는 효과 없는 비활성 호환 정의로 남겼다.
- 업데이트 시 로드된 수프 marker, 갈고리 낚시찌와 플레이어 임시 태그를 한 번 정리한다.
- 매 틱 함수는 도움말·모루 트리거와 플레이어 데이터 버전만 확인하도록 줄였다.
- 기존 양손 포션 합성 UX를 제거했다. 레드스톤·발광석 양방향 병용은 26.3 정식의 데이터 기반 양조 레시피가 확인된 뒤 구현하도록 보류했다.
- 검증·서버 시험·패키징·한영 번역을 핵심판 v1.1.0 기준으로 갱신했다.

## v1.0.1 — 2026-08-21

- 모루 도움말과 설치 절차에 `장비=왼쪽, 인챈트 책=오른쪽`, 설치·교체 뒤 `/reload`, 열린 모루 화면 재개방 순서를 명시했다.
- 실제 사용자 테스트에 남은 `강타 V + repair_cost 1` 네더라이트 검을 기준으로 `강타 V → 날카로움 V → 살충 V` 역순 런타임 회귀 검사를 추가했다.
- 공식 26.2 서버뿐 아니라 동일한 Fabric Loader 0.19.3 + Fabric API 0.157.0 환경에서도 세 인챈트의 순차 호환성 판정이 성공함을 보조 진단으로 확인했다. 팩 자체에는 모드 의존성을 추가하지 않았다.
- 개발용 호환성 검사가 강제로 구성요소를 삽입하는 데 그치지 않고, 모루가 사용하는 것과 같은 `canEnchant`·양방향 배타 판정을 통과하는지 확인하도록 강화했다.

## v1.0.0 — 2026-08-21

- 별도 제품명을 **인챈트플러스(Enchant Plus)**로 정하고 소스, 문서, 배포 ZIP, 테스트 서버와 작업 관리자 프로세스 식별자를 분리했다.
- 기존 월드와 아이템 저장값 호환을 위해 내부 `toybox` 네임스페이스, `tb_*` 트리거와 데이터 버전은 유지했다.
- 리소스팩이 없는 환경의 팩 제목, 도움말, 아이템·인챈트 이름, 모루 비용과 오류 안내 등 사용자 표시 fallback을 모두 한국어로 바꿨다.
- 선택 리소스팩을 적용한 경우에는 한국어 클라이언트가 한국어, 그 밖의 언어가 `en_us` 영어를 사용하도록 기존 언어 분기를 유지했다.
- 정적 검증에 모든 fallback과 `ko_kr` 값의 일치, 한국어/영어 제품명과 메시지 접두사 검사를 추가했다.

## v0.9.0-compat4 — 2026-08-19

- 자동·무료 모루 비용 초기화를 제거하고, 누적 작업 아이템과 네더의 별을 같은 모루 위에 던지는 재련 방식으로 교체했다.
- 성공한 대상 하나당 네더의 별을 정확히 1개 소모하며, 양쪽 아이템이 모루 위에 있고 `repair_cost`가 양수일 때만 실행한다.
- 인벤토리 변경 사건에서 실제 `repair_cost` 값을 설명창 첫 줄에 표시하고, 이후 갱신은 그 한 줄만 교체해 기존 사용자 로어를 보존한다.
- 재련 뒤에는 설명창을 `+0레벨`로 갱신한 다음 `repair_cost` 구성요소만 제거한다. 이름, 내구도, 인챈트, 장식과 사용자 지정 데이터는 유지한다.
- 아이템 투척 뒤 1틱에 해당 플레이어 4블록 주변만 검사한다. 매 틱 전역 아이템 엔티티 검색은 추가하지 않았다.
- `/trigger tb_anvil set 1`은 무료 우회로가 아니라 네더의 별 재련 안내로 변경했다.
- 공식 26.2 서버 스모크에 로어 삽입·제자리 갱신, 기존 로어 보존, `repair_cost 31→0`, 네더의 별 `2→1` 검사를 추가했다.

## v0.9.0-compat3 — 2026-08-19

- 인벤토리 변경과 모루 사용 사건에서 아이템의 `minecraft:repair_cost` 누적 작업 비용을 자동으로 제거한다.
- 자동 처리는 실제 누적 비용 구성요소가 발견될 때만 36칸 인벤토리와 장비 슬롯을 검사하며, 매 틱 전역 검색을 추가하지 않는다.
- 초기화 수정자는 `repair_cost` 구성요소만 제거하고 이름, 내구도, 인챈트, 장식과 사용자 지정 데이터를 보존한다.
- 재료 1개와 경험치 5레벨을 요구하던 초기 시안을 제거했다. `/trigger tb_anvil set 1`은 무료 주 손 수동 대체 경로로 남겼다.
- 순수 데이터팩에서 바꿀 수 없는 단일 모루 작업 40레벨 상한은 제한 사항으로 명시했다.
- `repair_cost=31` 시험 아이템으로 누적 비용 제거와 다른 구성요소 보존을 공식 서버 스모크에 추가했다.

## v0.9.0-compat2 — 2026-08-19

- 철퇴에서 육중 V, 격파 IV, 날카로움 V, 강타 V, 살충 V가 함께 붙도록 호환 범위를 확장했다.
- 날카로움의 공식 지원 태그에는 철퇴만 추가하고 마법부여대 기본 후보(`primary_items`)는 바꾸지 않았다.
- 피해 5종의 배타 태그에는 찌르기만 남겨 요청 밖의 삼지창 피해 조합은 계속 제한했다.
- 수선+무한, 다중 발사+관통, 보호 4종과 날카로움+강타+살충 호환은 그대로 유지했다.
- 철퇴 5종 런타임 스모크와 날개 결속 흉갑 7종 레시피 정적 검증을 추가했다.
- 날개 결속 흉갑은 순수 데이터팩에서 지원 가능한 제작 칸의 흉갑+겉날개 조합임을 도움말과 문서에 명시했다.

## v0.9.0-compat1 — 2026-08-19

- 기존 `Realm_Toybox v0.9.0-rc1`을 보존하고 별도 Vanilla Compat 변형 소스를 추가했다.
- 모든 바닐라 인챈트의 `max_level`을 Mojang Java 26.2 생성 데이터와 동일하게 복원했다.
- 날카로움·강타·살충은 서로 허용하되 찌르기·육중·격파와는 계속 배타적으로 유지했다.
- 보호 4종, 수선+무한, 다중 발사+관통의 `exclusive_set`만 제거했다.
- 섬세한 손길+행운, 급류+충성/집전 및 Toybox 전용 발사 인챈트 제한은 유지했다.
- 바닐라 상한을 우회하던 고등 마법부여 발전 과제, 함수 144개, 아이템 수정자 59개와 수동 시험 키트를 제거했다.
- `data/minecraft/tags/enchantment/exclusive_set` 전체 오버라이드와 빈 배타 태그를 만들지 않았다.
- 한국어/영어 선택 리소스팩을 변형판 전용으로 분리했다.
- 공식 26.2 정의와 허용 차이만 비교하는 `validate_compat.mjs`를 추가했다.
- 공식 서버용 로드·`/reload`·재시작 시험과 결정적 ZIP 패키징 스크립트를 변형판 이름으로 분리했다.
- 기존 수확 낫 스모크가 좌표 음수 쪽 청크를 암묵적으로 기대하던 문제를 고쳐, 경계의 네 청크를 명시적으로 강제 로드하도록 했다. 게임 기능 코드는 바꾸지 않았다.
