## 공식 서버 자동 시험

```powershell
& .\tools\test_server.ps1 -ServerJar ..\server-26.2.jar -PackArtifact .
```

소스와 최종 ZIP에 각각 실행한다.

1. 서버 JAR SHA-1과 정식 26.2·형식 107.1 확인
2. 새 평지 월드 부팅
3. 실제 `/reload`
4. 배포본과 별도로 설치한 `Enchant_Plus_Test_Harness`에서 `toybox:dev/server_smoke` 실행
5. 검·철퇴·방어구·활·쇠뇌의 허용 인챈트 조합을 양방향 호환 게이트로 확인
6. 누적 비용 로어 7→15 갱신과 기존 로어·구성요소 보존 확인
7. 모루 위 재련에서 더 가까운 비용 0 아이템을 건너뛰고 `repair_cost 31→없음`, 별 `2→1`, 관리 `+0` 로어 부재 확인
8. 숫돌 위 날개 결속 흉갑을 두 번 검사해 결속 구성요소 제거, 보존 항목 유지, 겉날개 정확히 1개 반환 확인
9. 레거시 runtime marker 1회 정리 확인
10. 로그의 JSON·함수·명령·레지스트리 오류 검색
11. 저장·정상 종료·같은 월드 재시작
12. PID·잠금 파일과 서버 JVM 잔존 여부 확인

성공 조건은 두 부팅 모두 `$smoke_fail=0`이며 Enchant Plus 데이터팩이 활성 목록에 있는 것이다.

## 실제 클라이언트 수동 시험

- 모루에서 각 허용 조합을 정방향·역방향으로 합치기
- 장비를 왼쪽, 책을 오른쪽에 넣었을 때 결과·경험치 확인
- 7종 흉갑+겉날개 제작과 구성요소 보존 확인
- 날개 결속 흉갑 활공·로켓·내구도·수선·수리 확인
- 실제 Q키로 대상과 별을 모루 위에 던져 별 1개만 소모되는지 확인
- 실제 Q키로 날개 결속 흉갑을 숫돌 윗면에 올려 흉갑·겉날개가 분리되는지 확인
- 비용이 0이거나 없는 일반 아이템에 `+0레벨` 설명이 생기지 않는지 확인
- 비용 없음, 모루 밖, 서로 멀리 있는 실패 조합에서 무소비 확인
- 두 플레이어가 가까운 서로 다른 모루를 동시에 사용할 때 혼선 확인
- 선택 리소스팩의 한국어/영어 전환
- 새 세계 생성 화면에서 실험 기능 경고가 뜨지 않는지 확인
- 백업 월드 Realm 업로드와 재시작 확인
