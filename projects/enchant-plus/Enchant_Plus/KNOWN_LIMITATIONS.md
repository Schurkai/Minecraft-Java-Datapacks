# KNOWN LIMITATIONS

## 포션

- v1.1.4에는 포션 합성과 포션 강화 기능이 없다.
- Java 26.2 정식은 데이터팩 양조 레시피를 지원하지 않는다. 레드스톤과 발광석을 모두 적용하는 바닐라형 UX는 26.3 정식 출시 뒤 `minecraft:brewing`으로 재검토한다.
- 26.3 스냅샷 기능은 현재 Realm용 26.2 팩에 넣지 않는다.

## 인챈트와 모루

- 공식 서버에서 모루와 같은 지원·배타 판정을 자동 검사하지만 실제 클라이언트 모루 UI 조작은 자동화하지 못했다.
- 철퇴의 날카로움은 책·모루 적용 대상으로만 추가했고 마법부여대 기본 후보는 넓히지 않았다.
- 보호 4종이 함께 붙어도 실제 피해 감소에는 바닐라 보호 계산 상한이 적용된다.
- 바닐라 모루의 한 작업당 40레벨 상한은 제거할 수 없다. 네더의 별 재련은 과거 작업 페널티만 초기화한다.
- 투척 감지는 플레이어가 네더의 별을 버린 뒤 80틱 동안 그 플레이어의 4블록 주변만 확인한다. 아이템과 별을 같은 모루 윗면에 가깝게 던져야 하며 디스펜서 등 플레이어 투척이 아닌 별은 감지하지 않는다.
- 실제 Q키 투척과 두 플레이어 동시 재련은 수동 미실행이다.

## 날개 결속

- 날개 결속은 사용자 정의 모루 레시피가 아니라 제작 칸 조합이다.
- 분리는 플레이어가 아이템을 버린 뒤 60틱 동안 4블록 주변만 검사한다. 지원 흉갑과 저장된 활공 구성요소가 숫돌 윗면에 있어야 한다.
- 다른 팩이나 명령으로 만든 활공 흉갑도 지원 7종 중 하나라면 분리 대상으로 인식될 수 있다.
- 공식 서버 자동 시험에서 분리와 복제 방지는 확인했지만 실제 클라이언트 Q키 투척, 7종 제작, 로켓 추진, 내구도·수선·팬텀 막 수리는 수동 미실행이다.

## 업데이트 호환

- 제거된 폭렬·균열 사격·도약·갈고리 인챈트 ID도 v1.1.4에는 없다. 옛 커스텀 인챈트 아이템이 있는 월드는 반드시 백업한 뒤 업그레이드해야 한다.
- 이미 만들어진 바람 병처럼 바닐라 구성요소만 가진 옛 아이템은 회수하지 않는다. 새 제작 레시피만 제거된다.
- v1.1.2 이하의 공개 `tb_help`, `tb_anvil`, `tb_pver`, `tb_data` objective는 첫 로드 때 `ep_*`로 마이그레이션한 뒤 제거한다. 그 밖의 제거된 옛 기능 objective는 월드 저장값에 남을 수 있지만 v1.1.4는 이를 활성화하거나 읽지 않는다.
- Realm Toybox와 인챈트플러스는 내부 `toybox` 네임스페이스가 같으므로 동시에 설치하면 안 된다.

## 언어·시험

- 리소스팩이 없으면 클라이언트 언어와 관계없이 한국어 fallback이 표시된다.
- 선택 리소스팩은 `ko_kr`와 `en_us`만 제공한다.
- Realm 업로드, 실제 UI, 2인 동시 조작과 장시간 성능 시험은 미실행이며 통과로 기록하지 않는다.
- 자동 시험은 인챈트 레지스트리 파일과 feature flag의 부재를 확인했지만, 실제 클라이언트 세계 생성 화면에서 실험 경고가 사라지는지는 아직 수동 미실행이다.
