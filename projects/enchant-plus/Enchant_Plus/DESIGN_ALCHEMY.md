# DESIGN_ALCHEMY — 보류

## 현재 상태

v1.1.4에는 포션 합성 코드가 없다. 양손에 포션을 들고 양조기를 사용하는 이전 UX는 제거했다.

## 후속 요구사항

- 일반 양조기 UI를 사용한다.
- 레드스톤 뒤 발광석, 발광석 뒤 레드스톤을 모두 허용한다.
- 일반·투척용·잔류형 포션을 지원한다.
- 한 포션을 다른 포션과 합치는 기능은 별도 UX가 합의될 때까지 구현하지 않는다.
- 실패 시 포션, 재료, 연료를 소비하지 않는다.
- Realms에서 매 틱 전역 양조기나 엔티티를 검색하지 않는다.

## 버전 조건

Java 26.2 정식에는 데이터팩용 양조 레시피 타입이 없다. 26.3 Snapshot 3에서 `minecraft:brewing`이 데이터 기반으로 추가됐지만 스냅샷은 대상이 아니다.

26.3 정식이 Realms에 적용되면 공식 서버 생성 데이터와 레시피 스키마를 다시 확인한 뒤, 네이티브 양조 레시피만으로 구현 가능한지 먼저 검증한다. 불가능한 부분이 있으면 구현 전에 UX를 다시 합의한다.
