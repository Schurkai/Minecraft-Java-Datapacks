# CHANGELOG

## v0.9.0-compat4 — 2026-08-19

- 자동·무료 모루 비용 초기화를 제거하고, 누적 작업 아이템과 네더의 별을 같은 모루 위에 던지는 재련 방식으로 교체했다.
- 성공한 대상 하나당 네더의 별을 정확히 1개 소모하며, 양쪽 아이템이 모루 위에 있고 `repair_cost`가 양수일 때만 실행한다.
- 인벤토리 변경 사건에서 실제 `repair_cost` 값을 설명창 첫 줄에 표시하고, 이후 갱신은 그 한 줄만 교체해 기존 사용자 로어를 보존한다.
- 재련 뒤에는 설명창을 `+0레벨`로 갱신한 다음 `repair_cost` 구성요소만 제거한다. 이름, 내구도, 인챈트, 장식과 사용자 지정 데이터는 유지한다.
- 아이템 투척 뒤 1틱에 해당 플레이어 4블록 주변만 검사한다. 매 틱 전역 아이템 엔티티 검색은 추가하지 않았다.
- `/trigger tb_anvil set 1`은 무료 우회로가 아니라 네더의 별 재련 안내로 변경했다.
- 공식 26.2 서버 스모크에 로어 삽입·제자리 갱신, 기존 로어 보존, `repair_cost 31→0`, 네더의 별 `2→1` 검사를 추가했다.

## v0.9.0-compat3 — 2026-08-19

- 인벤토리 변경과 모루 사용 사건에서 아이템의 `minecraft:repair_cost` 누적 작업 비용을 자동으로 제거한다.
- 자동 처리는 실제 누적 비용 구성요소가 발견될 때만 36칸 인벤토리와 장비 슬롯을 검사하며, 매 틱 전역 검색을 추가하지 않는다.
- 초기화 수정자는 `repair_cost` 구성요소만 제거하고 이름, 내구도, 인챈트, 장식과 사용자 지정 데이터를 보존한다.
- 자수정 1개와 경험치 5레벨 비용을 제거했다. `/trigger tb_anvil set 1`은 무료 주 손 수동 대체 경로로 남겼다.
- 순수 데이터팩에서 바꿀 수 없는 단일 모루 작업 40레벨 상한은 제한 사항으로 명시했다.
- `repair_cost=31` 시험 아이템으로 누적 비용 제거와 다른 구성요소 보존을 공식 서버 스모크에 추가했다.

## v0.9.0-compat2 — 2026-08-19

- 철퇴에서 육중 V, 격파 IV, 날카로움 V, 강타 V, 살충 V가 함께 붙도록 호환 범위를 확장했다.
- 날카로움의 공식 지원 태그에는 철퇴만 추가하고 마법부여대 기본 후보(`primary_items`)는 바꾸지 않았다.
- 피해 5종의 배타 태그에는 찌르기만 남겨 요청 밖의 삼지창 피해 조합은 계속 제한했다.
- 수선+무한, 다중 발사+관통, 보호 4종과 날카로움+강타+살충 호환은 그대로 유지했다.
- 철퇴 5종 런타임 스모크와 날개 결속 흉갑 7종 레시피 정적 검증을 추가했다.
- 날개 결속 흉갑은 순수 데이터팩에서 지원 가능한 제작 칸의 흉갑+겉날개 조합임을 도움말과 문서에 명시했다.

## v0.9.0-compat1 — 2026-08-19

- 기존 `Realm_Toybox v0.9.0-rc1`을 보존하고 별도 Vanilla Compat 변형 소스를 추가했다.
- 모든 바닐라 인챈트의 `max_level`을 Mojang Java 26.2 생성 데이터와 동일하게 복원했다.
- 날카로움·강타·살충은 서로 허용하되 찌르기·밀도·격파와는 계속 배타적으로 유지했다.
- 보호 4종, 수선+무한, 다중 발사+관통의 `exclusive_set`만 제거했다.
- 섬세한 손길+행운, 급류+충성/집전 및 Toybox 전용 발사 인챈트 제한은 유지했다.
- 바닐라 상한을 우회하던 고등 마법부여 발전 과제, 함수 144개, 아이템 수정자 59개와 수동 시험 키트를 제거했다.
- `data/minecraft/tags/enchantment/exclusive_set` 전체 오버라이드와 빈 배타 태그를 만들지 않았다.
- 한국어/영어 선택 리소스팩을 변형판 전용으로 분리했다.
- 공식 26.2 정의와 허용 차이만 비교하는 `validate_compat.mjs`를 추가했다.
- 공식 서버용 로드·`/reload`·재시작 시험과 결정적 ZIP 패키징 스크립트를 변형판 이름으로 분리했다.
- 기존 수확 낫 스모크가 좌표 음수 쪽 청크를 암묵적으로 기대하던 문제를 고쳐, 경계의 네 청크를 명시적으로 강제 로드하도록 했다. 게임 기능 코드는 바꾸지 않았다.
