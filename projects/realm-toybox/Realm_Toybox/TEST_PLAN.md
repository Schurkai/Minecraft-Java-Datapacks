## 실제 클라이언트가 필요한 수동 항목

- RC2 수동 키트는 OP 권한, 빈 인벤토리, 구조물에서 떨어진 열린 공간, 폐기 가능하거나 백업된 시험 월드에서만 실행한다. `/function toybox:dev/client_test_kit`은 현재 경험치 점수와 레벨을 0으로 만든 뒤 227레벨을 지급하므로 일반 생존 월드에서 실행하지 않는다.
- 키트 실행 뒤 전방 리그가 `60/60 active shelves`로 보고되는지 먼저 확인한다. 60보다 작으면 블록에 막힌 불완전 설치이므로 기능 시험을 진행하지 말고 시험 마법부여대 위에 선 채 `/function toybox:dev/client_test_cleanup`을 실행한 뒤 위치를 바꾼다.
- 날카로움 V 장비와 V–IX 책을 순서대로 사용해 X까지 올린다. X 시도 직전에 외곽 책장 하나를 제거해 59책장·무소비 실패를 확인하고 복구한다. X에서 내구성 III, 이름, lore, 손상 37, 수리 비용 17, 시험 `custom_data`가 모두 남는지 기록한다.
- `/function toybox:dev/client_test_potency` 뒤 TEST A를 합쳐 신속 V 30,000틱과 잔여 74레벨, `/function toybox:dev/client_test_duration` 뒤 TEST B를 합쳐 투척용 신속 IV 72,000틱과 잔여 9레벨을 확인한다. TEST C를 합쳐 서로 다른 5효과 잔류형과 경험치·정확 예산 재료 0을 확인한 뒤 실제로 던진다.
- `/function toybox:dev/client_test_reject`의 `strong_turtle_master` 쌍은 병·재료·경험치가 전혀 소비되지 않아야 한다. 보존 검사를 기록한 뒤 `/function toybox:dev/client_test_cleanup`을 실행한다. 시험 태그가 보존된 강화 검은 삭제되지만 새 혼합 물약, 경험치와 이미 적용된 효과는 자동 정리되지 않는다는 점을 별도로 확인한다.
- 위 보조 키트가 성공해도 날카로움 한 경로, 포션 긍정 경계 3개, 거부 경계 1개만 다룬다. 다음의 전체 수동 항목, 2인 동시성, 장시간 시험, 실제 Realm 업로드를 대신하지 않으며 실행하지 않은 항목은 통과로 기록하지 않는다.
- 인챈트 책 제작/모루 적용/상한/필수 허용 조합과 유지 제한.
- 고등 마법부여의 마법부여대 우클릭 진입, 주 손 장비/보조 손 단일 인챈트 책 판정, 같은 현재 레벨 요구, 지원 인챈트별 시작 단계와 상한.
- 고등 마법부여의 정확한 60개 고정 책장 슬롯, 15/24/32/40/48/60개 경계, 각 슬롯의 전송 통로 차폐, 마법부여대를 바라보는 방향·거리 경계.
- 고등 마법부여 성공·재료/책장/레벨 부족·적용 실패에서 책, 청금석, 자수정, 경험치의 소비 여부와 이름·내구도·장식·수리 비용·다른 인챈트·사용자 데이터 보존.
- 포션 합성의 양손 일반·투척·잔류형 조합과 양조기 우클릭, 단일 동일 효과의 발광석 강도/레드스톤 시간 모드, 서로 다른 최대 5효과 합집합.
- 포션 합성의 I→V 및 1→72000틱 경계, 즉시 회복·피해, 상충 효과, 병 승격용 화약·드래곤의 숨결, 경험치·자수정 비용.
- 입력 병 내부 중복 효과, 다중 효과 병 사이의 겹치는 효과, `hidden_effect`, 6번째 효과, 0/VI 단계, 0/72001틱, `strong_turtle_master` 감속 VI가 모두 무소비로 거부되는지 확인.
- 합성 결과가 입력 병의 이름·lore·custom color 등 비포션 컴포넌트를 보존하지 않고 고정 `Mixed Potion` 컴포넌트로 재구성되는지 확인.
