# 수확 낫 클라이언트 수동 시험

대상은 Minecraft Java Edition 26.2와 Realm Toybox v0.9.0-rc1이다. 이 문서는 절차이며, 실행 전 항목은 통과로 기록하지 않는다. 백업한 일회용 월드와 빈 시험 농장을 사용한다.

## 준비

1. 제작대에서 `철 철 자수정 / 빈칸 막대 빈칸 / 빈칸 막대 빈칸` 배치로 수확 낫을 만든다.
2. 밀·당근·감자·비트를 같은 높이의 경작지에, 네더 사마귀를 같은 높이의 영혼 모래에 준비한다. 완숙 9칸과 미성숙 비교 칸을 각각 둔다.
3. F3+H 고급 툴팁 또는 `/data get entity @s SelectedItem`으로 시험 전 손상값을 기록한다.

## 핵심 동작

- [ ] 주 손 낫으로 5블록 안의 완숙 작물을 겨냥해 사용 키를 누르면 중심 기준 같은 높이 3×3의 완숙 작물만 수확된다.
- [ ] 밀·당근·감자·비트·네더 사마귀가 각각 작동하고 미성숙 작물은 남는다.
- [ ] 수확물은 바닥에 나오며 자동 재파종되지 않는다.
- [ ] 한 칸만 익었어도 성공한 한 번의 손상값은 정확히 1 증가하고, 빈 공간·미성숙만 겨냥하면 증가하지 않는다.
- [ ] 보조 손에서도 작동하며 주 손에 다른 아이템이 있을 때 손 선택이 의도대로다.
- [ ] 꽃·키 큰 풀·고체 블록이 시선 앞에 있으면 그 뒤 작물이 수확되지 않는다.
- [ ] 5블록 안쪽은 작동하고 사거리 밖은 작동하지 않는다.

## 경계와 회귀

- [ ] 행운 없음과 행운 III에서 바닐라 작물 드롭 차이가 나타나며 아이템 복제가 없다.
- [ ] 내구성 III가 있어도 Toybox 스윕당 내구도 1이 드는 문서화된 정책과 일치한다.
- [ ] 마지막 내구도에서 낫이 한 번만 파손되고 작물과 드롭이 중복되지 않는다.
- [ ] 수선과 모루 수리가 일반 철 괭이처럼 가능하다.
- [ ] 사용 키를 계속 눌렀을 때 약 10틱 재무장 간격으로만 반복되고 공격·블록 설치·방패 동작에 예상 밖 간섭이 없다.
- [ ] 두 플레이어가 겹친 3×3을 동시에 수확해도 동일 작물 중복 드롭, 상대 낫 손상, 남은 활성 태그가 없다.
- [ ] `/reload`, 재접속, 서버 재시작 후 기존 낫이 계속 식별되고 동작한다.
- [ ] 한국어 리소스팩에서 이름·설명이 한국어, 다른 언어에서 영어이며 리소스팩 없이도 영어 fallback과 기능이 유지된다.

관찰값과 실패 재현 절차만 `TEST_REPORT.md`에 기록한다. 체크하지 않은 항목은 미실행이다.
