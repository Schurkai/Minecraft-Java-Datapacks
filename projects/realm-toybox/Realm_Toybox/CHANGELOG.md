- 철 괭이 기반 전용 `수확 낫`을 추가했다. 철 주괴 2개·자수정 조각 1개·막대기 2개로 제작하며, 주 손과 보조 손을 모두 지원한다.
- `minecraft:using_item` 사건에서만 시작해 시선 방향 최대 5블록을 0.2블록씩 25회 제한 추적한다. 맞은 완숙 작물을 중심으로 같은 Y 높이 3×3의 밀·당근·감자·비트·네더 사마귀만 수확한다.
- 각 블록은 먼저 `loot ... mine ... mainhand/offhand`로 바닐라 도구 전리품과 행운 문맥을 생성한 뒤 공기로 바꾼다. 복제를 피하기 위해 자동 재파종은 하지 않으며, 한 번이라도 수확했을 때만 내구도 1을 소모한다.
- 10틱 재무장은 `toybox.sickle_active` 태그가 있는 사용자만 처리한다. 월드의 작물·아이템·엔티티를 매 틱 전역 검색하지 않는다.
- 공식 26.2 서버 스모크를 고정 시드 평지 월드로 결정론화했다. 완숙 5종 9칸, 미성숙 비수확, 내구도 1, 마지막 내구도 파손, 정리를 신규 부팅·`/reload`·재시작에서 확인했다.
- 26.2 엔티티 장비 직렬화가 `HandItems[0]`이 아니라 `equipment.mainhand`임을 실제 NBT로 확인해 내구도 검사의 거짓 실패를 수정했다. 서버 RCON 읽기 제한은 느린 전체 스모크를 위해 유한 60초로 늘렸다.
- 데이터 버전을 900으로 올리고 v0.9 objective/플레이어 마이그레이션, 정적 규칙, 수동 시험 문서, 한국어/영어 번역을 추가했다. 실제 클라이언트 사용 키 진입·손 교체·조작감과 Realm은 아직 미실행이다.

## v0.8.0-rc1 — 2026-08-11

- 줄자 결과에 양 끝 블록을 포함한 X/Y/Z 크기, XZ 바닥 면적, 수직 4면 면적과 부피를 추가했다. 기존 축 차이 26,000 상한 안에서 두 축 곱은 항상 안전하며, 마지막 벽면 배수와 세 축 부피는 signed 32-bit 범위를 넘기 전에 나눗셈 기반 상한 검사로 생략한다.
- 분필 슬롯 1–8을 가리키는 분필 나침반을 추가했다. 개조하지 않은 일반 나침반 정확히 1개와 자수정 조각 1개를 준비하고 `/trigger tb_compass set 1..8`을 실행하면 좌표·차원·슬롯 설명과 `minecraft:lodestone_tracker`를 가진 비중첩 나침반으로 교체된다.
- 나침반 목표는 `tracked:false`이므로 실제 자석석, 목표 블록, 강제 청크 로딩이 필요 없다. 다른 차원에서는 바닐라 나침반처럼 회전하며 기존 각인·사용자 지정 나침반은 컴포넌트 손실을 막기 위해 거부한다.
- 모든 나침반 작업은 trigger 한 번 안에서 동기적으로 끝나고, 아이템 교체 성공 뒤에만 자수정 1개를 소비한다. 매 틱 좌표 계산, marker, 예약 함수, 전역 엔티티 검색은 추가하지 않았다.
- 데이터 버전을 800으로 올리고 `tb_compass` trigger와 v0.8 플레이어 마이그레이션을 추가했다. 생성기 `generate_v080.mjs`, 3차원 나침반 컴포넌트·산술 경계 공식 서버 스모크, 정적 규칙과 검증기 음성 fixture 12개를 추가했다.
- Mojang 공식 Java 26.2 서버의 소스 디렉터리에서 신규 부팅, 실제 `/reload`, 전체 스모크 0, 저장·정상 종료와 같은 월드 재시작을 통과했다. 실제 클라이언트 바늘 방향·trigger 아이템 교체·2인 동시성·Realm은 아직 미실행이다.

- 정적 검증에 v0.5 objective/마이그레이션, 거리 상한·제곱근 반복 수, 8개 슬롯, 세 바닐라 차원 매크로, 플레이어 전용 입자, storage 정리, `summon`/`schedule` 금지를 추가했다. 고의 오류 음성 fixture는 8개로 늘렸다.

- 특수 화살은 플레이어가 활·쇠뇌로 발사한 탄약의 `custom_data` 보존을 실제 클라이언트에서 먼저 증명해야 하는 G0가 남아 있어 이번 릴리스에 구현하지 않았다.

## v0.4.0-rc2 — 2026-08-01

- 실제 클라이언트에서 고등 마법부여와 포션 합성의 핵심 경계를 한 흐름으로 확인할 수 있는 개발용 수동 테스트 키트를 추가. `/function toybox:dev/client_test_kit`은 플레이어 전방 8블록에 `keep` 배치로 마법부여대·책장 60개·양조기를 만들고, 정확 예산 시험 아이템을 지급한다.
- 날카로움 V→X와 X 직전 책장 59개 무소비 실패, 대상 외 컴포넌트 보존, 신속 IV→V/30,000틱, 신속 IV 시간 합산→투척용 72,000틱, 서로 겹치지 않는 5효과 잔류형 합집합을 한 번에 검사하도록 경험치 227레벨·청금석 21개·자수정 24개의 정확 예산을 구성했다.
- 발광석과 레드스톤을 동시에 소지하면 같은 효과 합성 모드가 모호해지므로 `/function toybox:dev/client_test_potency`와 `/function toybox:dev/client_test_duration`으로 각각 4개씩 따로 지급한다. `/function toybox:dev/client_test_reject`은 `strong_turtle_master`가 무소비로 거부되는지 확인하는 입력을 제공한다.
- `/function toybox:dev/client_test_cleanup`은 플레이어가 시험 마법부여대 바로 위에 섰을 때 발밑 리그와 태그가 남은 시험 검·입력을 정리한다. 영속 marker와 엔티티 검색은 사용하지 않는다. 강화된 시험 검도 태그가 보존되어 삭제되지만, 새 혼합 물약·추가한 경험치·적용된 효과는 복원·삭제하지 않는다. 같은 슬롯의 기존 책장·마법부여대·양조기를 출처별로 구분할 수도 없으므로 빈 인벤토리의 폐기 가능한 시험 월드 전용이다.
- 정적 검증 대상에 키트의 틱 비연결, 예약 함수 금지, 60책장 `keep` 배치, 정확 예산, 모드 가루 분리, 엔티티 없는 발밑 정리를 추가하고 공식 서버 스모크 대상에 리그 설치·60책장 계수·정리를 추가했다. 정적 검사와 공식 26.2 헤드리스 서버 소스 시험은 통과했으나, 실제 클라이언트와 Realm 검증은 계속 미실행 상태다.
- 영구 gameplay state, objective, storage 스키마를 바꾸지 않았으므로 표시 릴리스는 RC2로 올리되 데이터 버전은 400을 유지한다.

- `minecraft:default_block_use` 발전 과제로 양조기 사용 순간에만 실행되는 양손 포션 합성을 구현. 바닐라 기본 포션과 `custom_effects`를 40개 허용 효과의 정규 목록으로 합친다.
- 같은 단일 효과에 발광석만 소지하면 같은 단계 두 병을 한 단계 높이고, 레드스톤만 소지하면 단계 차 1 이하의 시간을 합산한다. 결과는 최대 V, 72,000틱이며 즉시 효과도 단계 상승을 지원한다.
- 서로 겹치지 않는 효과는 최대 5종까지 합치고 일반·투척용·잔류형 중 높은 병 형태를 유지한다. 필요한 경우 화약 또는 드래곤의 숨결을 추가로 소비한다.
- 포션 비용은 효과 단계·지속시간 점수로 경험치 레벨을 계산하고, 합성 모드별 발광석/레드스톤/자수정을 요구한다. 결과 적용 실패·지원하지 않는 효과·중복·상한 초과·비용 부족에서는 입력과 재료를 소비하지 않는다.
- 두 시스템은 틱 경로와 전역 엔티티 검색을 사용하지 않으며 한 이벤트 함수 안에서 동기적으로 임시 점수·storage를 만들고 지운다.
- 정적 검증과 공식 서버용 개발 스모크에 발전 과제 연결, 59개 수정자, 다른 컴포넌트 보존, 단일 책 키 수, 60책장/차폐, 기본·커스텀 포션 정규화, V/72,000 상한, 5효과 상한과 세 병 형태 생성을 추가. 실제 클라이언트 클릭 UX와 2인 동시 사용은 아직 통과로 기록하지 않는다.
