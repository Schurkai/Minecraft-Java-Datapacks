# Realm Toybox 클라이언트 수동 시험

이 문서는 Minecraft Java Edition 26.2 클라이언트에서 `v0.4.0-rc2`의 고등 마법부여와 포션 합성을 직접 확인하기 위한 절차입니다. 시험 키트가 명령과 입력물을 제공한다는 사실은 클라이언트 시험을 실행했다는 뜻이 아닙니다. 아래 동작을 실제로 수행하고 결과를 따로 기록해야 합니다.

## 시작 전 경고

- 원본 월드가 아닌 **백업된 일회용 시험 월드**를 사용하십시오. 명령을 실행할 플레이어에게 운영자 권한이 필요합니다.
- 인벤토리를 완전히 비우고, 앞쪽에 충분한 빈 공간이 있는 평지에서 실행하십시오. 키트는 플레이어가 보는 수평 방향으로 8블록 앞에 마법부여대를 기준으로 한 시험장을 만듭니다.
- 시작 명령은 현재 경험치를 레벨과 포인트 모두 0으로 만든 뒤 정확히 **227레벨**을 지급합니다. 기존 경험치는 복구하지 않습니다.
- 시험장 블록은 `keep` 방식으로 배치되어 지형을 덮어쓰지는 않지만, 원래 그 자리에 있던 책장·마법부여대·양조기는 정리 명령이 제거할 수 있습니다. 그래서 반드시 일회용 빈 공간을 사용해야 합니다.
- 인벤토리가 비어 있지 않으면 지급물이 밖으로 떨어질 수 있으며, 정리 명령은 바닥에 떨어진 아이템 엔티티를 제거하지 않습니다.

## 1. 한 명령으로 준비

데이터팩을 활성화하고 `/reload`한 뒤 다음 명령을 한 번 실행합니다.

```mcfunction
/function toybox:dev/client_test_kit
```

명령은 시험용 장비·책·포션·정확한 수량의 재료를 지급하고, 앞쪽에 마법부여대·60개 책장·양조기를 설치합니다. 채팅에 표시되는 활성 책장 수가 반드시 **`60/60`**이어야 합니다. 60보다 적으면 시험을 진행하지 말고, 시험 마법부여대 위에 선 채 정리 명령을 실행한 다음 더 넓은 빈 공간으로 이동해 처음부터 다시 준비합니다.

초기 예산은 다음과 같습니다.

- 경험치 227레벨
- 청금석 21개
- 자수정 조각 24개
- 화약 1개
- 드래곤의 숨결 1개
- 발광석 가루와 레드스톤 가루는 아직 없음

## 2. 고등 마법부여 V → X

1. `[TEST]` 다이아몬드 검을 주 손, 날카로움 V 책을 보조 손에 들고 시험장의 마법부여대를 사용하여 VI를 만듭니다.
2. 결과 검과 날카로움 VI, VII, VIII 책을 차례로 양손에 들고 사용하여 VII, VIII, IX까지 올립니다. IX 책은 마지막 시험을 위해 남겨 둡니다.
3. X 시도 직전 바깥 고리의 활성 책장 하나를 부숩니다. IX 검과 IX 책으로 마법부여대를 사용했을 때 실패하며 책·경험치·재료가 전혀 줄지 않아야 합니다.
4. 부순 책장을 같은 자리에 복구하고 다시 사용하여 날카로움 X를 만듭니다.

날카로움 X가 된 직후 다음을 확인합니다.

- 경험치 **127레벨**, 청금석 **0개**, 자수정 조각 **9개**
- 검의 내구성 III, 사용자 이름, 설명, 손상도 37, 모루 누적 비용 17이 그대로 유지됨
- 주 손에 검을 든 상태에서 `/data get entity @s SelectedItem`을 실행했을 때 `toybox.client_test`와 `preserve_test` 표식이 유지됨

## 3. 포션 단계 상승

발광석 가루와 레드스톤 가루를 동시에 소지하면 같은 효과 합성 모드를 고를 수 없으므로, 다음 단계 명령이 기존 시험용 모드 가루를 정리하고 필요한 것만 지급합니다.

```mcfunction
/function toybox:dev/client_test_potency
```

인벤토리에 레드스톤 가루가 전혀 없는지 확인합니다. `[TEST A]` 신속 IV 일반 포션 두 병을 주 손과 보조 손에 하나씩 들고 양조기를 사용합니다.

예상 결과:

- 신속 V, 30,000틱인 일반 포션 1병
- 경험치 **74레벨**, 발광석 가루 **0개**, 자수정 조각 **7개**

## 4. 포션 시간 연장

다음 명령으로 시험용 발광석 가루를 없애고 레드스톤 가루 4개만 받습니다.

```mcfunction
/function toybox:dev/client_test_duration
```

인벤토리에 발광석 가루가 전혀 없는지 확인합니다. `[TEST B]` 신속 IV 일반 포션과 신속 IV 투척용 포션을 양손에 들고 양조기를 사용합니다.

예상 결과:

- 신속 IV, 72,000틱인 투척용 포션 1병
- 경험치 **9레벨**, 레드스톤 가루 **0개**, 자수정 조각 **5개**, 화약 **0개**

## 5. 다섯 효과 합치기

`[TEST C]` 일반 2효과 포션과 잔류형 3효과 포션을 양손에 들고 양조기를 사용합니다.

예상 결과:

- 야간 투시, 신속, 힘, 행운, 화염 저항이 들어 있는 잔류형 5효과 포션 1병
- 경험치, 청금석, 자수정 조각, 발광석 가루, 레드스톤 가루, 화약, 드래곤의 숨결이 모두 **0**
- 완성된 포션을 던졌을 때 잔류형 효과 구름이 생성됨

## 6. 거부 경로

다음 명령으로 거부 시험용 두 병을 받습니다.

```mcfunction
/function toybox:dev/client_test_reject
```

`[TEST D]` 강한 거북 도사의 물약과 신속 포션을 양손에 들고 양조기를 사용합니다. 합성이 실패하고 두 입력 병, 경험치, 재료가 전혀 소비되지 않아야 합니다.

## 7. 정리

시험 마법부여대 블록 바로 위에 선 뒤 다음 명령을 실행합니다.

```mcfunction
/function toybox:dev/client_test_cleanup
```

정리 명령은 플레이어 발밑의 시험 마법부여대를 원점으로 삼아 마법부여대·책장·양조기를 제거하고, 플레이어 인벤토리에 남아 있는 시험 표식 입력물을 지웁니다. 영속 marker나 전역 엔티티 검색은 사용하지 않습니다. 다음 항목은 정리하지 않습니다.

- 명령으로 바뀐 경험치 또는 지급된 227레벨
- 합성·마법부여가 끝난 결과물
- 인벤토리 밖으로 떨어뜨린 시험 아이템
- 플레이어가 시험 마법부여대 바로 위에 서 있지 않은 시험장
- 시험장 위치에 나중에 놓은 같은 종류의 블록과 원래 있던 같은 종류의 블록을 구분하지 못하므로, 해당 블록도 제거될 수 있음

정리 전에 부순 책장은 반드시 원래 시험 슬롯에 복구하십시오. 시험장을 찾지 못했다는 메시지가 나오면 시험 마법부여대 위에 정확히 선 뒤 다시 실행합니다.
