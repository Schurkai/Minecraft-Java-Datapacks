# 포션 합성 구현

상태: v0.4.0-rc2 구현, 라이브 클라이언트 검증 전

## 목표와 사용법

일반·투척용·잔류형 포션 두 병을 순수 데이터팩으로 합쳐 효과 단계 최대 V, 지속시간 최대 72,000틱, 서로 다른 효과 최대 5종의 `혼합 물약`을 만든다. 바닐라 양조기 슬롯이나 레시피를 확장하지 않는다.

1. 합칠 포션을 주 손과 보조 손에 한 병씩 든다.
2. 같은 단일 효과의 단계 상승은 인벤토리에 발광석 가루만, 시간 연장은 레드스톤만 준비한다. 두 가루를 모두 소지하면 모드를 확정할 수 없어 실패한다.
3. 서로 겹치지 않는 효과를 합칠 때는 별도 모드 가루가 필요 없다.
4. 필요한 자수정, 경험치와 병 승격 재료를 준비하고 양조기를 사용한다.

양조기의 `minecraft:default_block_use` 발전 과제가 클릭 순간에만 함수를 실행하고 즉시 revoke된다. 별도 `/trigger`, 미리보기, 확인 창은 없다. 성공하면 주 손 병이 결과로 바뀌고 보조 손 병과 비용이 사라진다.

## 입력 정규화

`SelectedItem`과 보조 손 `Inventory[{Slot:-106b}]`의 전체 아이템 데이터를 임시 storage로 복사한다. `minecraft:potion_contents.potion`에 있는 공식 기본 포션을 명시적인 효과 목록으로 펼친 뒤 `custom_effects`를 이어 붙인다.

허용 조건:

- 일반·투척용·잔류형 포션
- 구현에 등록된 바닐라 효과 ID 40개
- 입력 단계 I–V(`amplifier` 0–4)
- 입력 지속시간 1–72,000틱
- 한 병 안에 같은 효과 ID가 한 번만 존재
- `hidden_effect`가 없음

지원 효과:

`absorption`, `bad_omen`, `blindness`, `breath_of_the_nautilus`, `conduit_power`, `darkness`, `dolphins_grace`, `fire_resistance`, `glowing`, `haste`, `health_boost`, `hero_of_the_village`, `hunger`, `infested`, `instant_damage`, `instant_health`, `invisibility`, `jump_boost`, `levitation`, `luck`, `mining_fatigue`, `nausea`, `night_vision`, `oozing`, `poison`, `raid_omen`, `regeneration`, `resistance`, `saturation`, `slow_falling`, `slowness`, `speed`, `strength`, `trial_omen`, `unluck`, `water_breathing`, `weakness`, `weaving`, `wind_charged`, `wither`.

알 수 없는 기본 포션·효과 ID, 중복, 숨은 연쇄 효과, VI 이상, 72,000틱 초과는 아무것도 소비하지 않고 거부한다. 공식 `strong_turtle_master`에는 VI 감속이 들어 있어 입력 상한 때문에 거부된다.

## 합성 모드

### 같은 단일 효과: 단계 상승

- 양쪽 병에 효과가 정확히 하나씩 있고 ID와 단계가 같아야 한다.
- 입력 단계 I–IV만 가능하며 결과는 한 단계 상승한다.
- 시간 효과의 결과 지속시간은 더 짧은 입력의 75%를 버림 계산한다.
- 즉시 회복·즉시 피해는 결과 지속시간 1틱으로 둔다.
- 발광석 가루는 결과 amplifier 값만큼, 최소 1개다. 즉 II=1, III=2, IV=3, V=4개다.
- 자수정은 기본 1개이며 결과가 III 이상이면 1개를 더 써서 최대 2개다.

### 같은 단일 효과: 시간 연장

- 양쪽 효과 ID가 같고 단계 차가 1 이하여야 한다.
- 결과 단계는 둘 중 낮은 단계다.
- 두 지속시간을 더하고 72,000틱에서 자른다.
- 레드스톤은 `ceil(결과 지속시간/18000)`개이며 최대 4개다.
- 자수정은 결과가 I–II면 1개, III–V면 2개다.
- 즉시 효과는 이 모드를 지원하지 않는다.

### 서로 다른 효과: 합집합

- 두 병의 모든 효과 ID가 서로 겹치지 않아야 한다.
- 입력 효과를 고정 ID 순서로 합쳐 최대 5종까지 보존한다.
- 한 ID라도 겹치는 다중 효과 포션끼리는 병합하지 않는다.
- 자수정 비용은 `결과 효과 수 + 두 입력에 있던 III 이상 효과 수`다.
- 발광석과 레드스톤은 소비하지 않는다.

신속/감속, 재생/독처럼 반대 성격의 **서로 다른 ID**는 자동 상쇄하지 않으며 함께 들어갈 수 있다.

## 병 형태와 비용

결과 병은 일반 < 투척용 < 잔류형 중 높은 형태를 따른다.

- 두 병 형태가 같으면 승격 재료 없음
- 결과가 투척용이고 입력 중 일반 포션이 있으면 화약 1개
- 결과가 잔류형이고 입력 중 일반 또는 투척용이 있으면 드래곤의 숨결 1개

잔류형으로 바로 올라갈 때 구현은 드래곤의 숨결만 요구하며 화약을 추가로 요구하지 않는다.

효과별 점수는 다음과 같다.

`S_effect=(amplifier+1)² × max(1,floor(duration/1200))`

전체 점수 `S`는 결과 효과의 점수 합이며 경험치 비용은 `3+ceil(2×sqrt(S))` 레벨이다. 즉시 효과의 1틱도 duration 단위 1로 계산한다.

## 결과 아이템과 소비 순서

결과는 동적 item component 매크로로 새 아이템 스택을 만든다.

- `minecraft:potion_contents.custom_effects`: 정규화된 결과 목록
- `custom_color`: 고정 보라색 `9133302`
- `custom_name`: 번역 키가 있는 `혼합 물약`/`Mixed Potion`
- `custom_data.toybox.mixed_potion=true`

입력의 사용자 이름, lore, 사용자 색, 기타 비효과 컴포넌트는 결과에 복사하지 않는다. 효과 목록 안의 허용된 표시 필드는 원본 항목에서 이어질 수 있지만 별도의 정렬된 lore는 만들지 않는다.

모든 입력·상한·비용을 먼저 검사하고, 주 손을 결과 병으로 교체하는 명령의 성공을 확인한 뒤 보조 손 병, 자수정, 모드 가루, 승격 재료, 경험치를 소비한다. 결과 적용 실패 시 보조 손과 비용은 소비하지 않는다.

## 사건 기반 처리와 동시성

포션 합성 함수는 틱 함수에서 호출되지 않고 양조기 사용 사건에서만 실행된다. 임시 storage `toybox:scratch alchemy`와 fake-player 점수는 함수 시작 시 초기화하고 종료 전에 삭제한다. 서버 명령은 주 스레드에서 순차 실행되므로 한 이벤트의 동기 함수 사이에 다른 플레이어 합성이 끼어들지 않는다. 드롭 아이템, 전용 컨테이너, marker/interaction 엔티티, 예약 함수는 사용하지 않는다.

## RC2 수동 시험 보조 키트

`/function toybox:dev/client_test_kit`은 포션 합성의 대표 긍정 경계 세 개를 실제 클라이언트에서 순서대로 확인하도록 입력과 통합 정확 예산을 지급한다. 키트 전체는 경험치 227레벨, 청금석 21개, 자수정 24개를 사용하며 그중 포션 경로는 고등 마법부여가 끝난 뒤 남은 127레벨과 자수정 9개, 화약 1개, 드래곤의 숨결 1개를 사용한다.

시험 순서는 다음과 같다.

1. `/function toybox:dev/client_test_potency`로 전용 발광석 4개만 받은 뒤 같은 신속 IV 40,000틱 일반 포션 두 병을 합친다. 결과는 신속 V 30,000틱이고 비용은 경험치 53레벨·자수정 2개·발광석 4개여서 통합 시험 레벨이 74가 되어야 한다.
2. `/function toybox:dev/client_test_duration`으로 남은 전용 모드 가루를 지우고 레드스톤 4개만 받은 뒤 신속 IV 40,000틱 일반+투척용 두 병을 합친다. 결과는 투척용 신속 IV 72,000틱이고 비용은 경험치 65레벨·자수정 2개·레드스톤 4개·화약 1개여서 9레벨이 남아야 한다.
3. 밤의 투시+신속 일반 포션과 힘+행운+화염 저항 잔류형 포션을 합친다. 결과는 서로 겹치지 않는 5효과 잔류형이며 경험치 9레벨·자수정 5개·드래곤의 숨결 1개를 소비해 정확 예산이 0이 되어야 한다. 결과는 실제로 던져 효과와 잔류 구름을 확인한다.
4. `/function toybox:dev/client_test_reject`으로 공식 `strong_turtle_master`와 신속 병을 받은 뒤 합성을 시도한다. amplifier 5 감속 때문에 병·재료·경험치가 전혀 소비되지 않아야 한다.

발광석과 레드스톤을 동시에 소지하면 같은 단일 효과의 모드를 결정할 수 없으므로 두 단계 함수는 태그가 붙은 기존 모드 가루를 먼저 지우고 필요한 가루 하나만 지급한다. 일반 인벤토리에 별도 발광석·레드스톤이 있으면 조건을 오염시키므로 빈 인벤토리가 필요하다.

이 키트는 신속 한 효과의 강도·시간, 한 5효과 합집합, 공식 VI 거부만 다룬다. 40개 효과 전체, 즉시 효과, 겹치는 다중 효과, 모든 비정상 duration/amplifier, 실제 투척 거리, 빠른 손 교체, 2인 동시성은 대신하지 않는다. `/function toybox:dev/client_test_cleanup`도 합성 결과와 XP, 던진 물약 효과를 되돌리지 않는다.

## 검증 범위와 남은 수동 시험

26.2/data pack 107.1용 advancement·함수·item component 구문과 다음 개발 스모크를 추가했다.

- 기본 신속 포션 정규화와 II/2,700틱 단계 상승
- custom effect IV→V, 40,000+40,000틱→72,000틱 상한
- 공식 VI 효과 입력 거부
- 서로 다른 기본 효과 합집합과 6효과 거부
- 일반·투척용·잔류형 결과 아이템 생성
- 결과 V/72,000틱, 이름과 Toybox 표식

RC2는 수동 키트의 정확 예산과 강도/시간 가루 분리, 리그 양조기 설치·정리를 정적 검증과 공식 서버 리그 스모크 대상으로 추가했다. 이는 실제 양조기 클릭이나 음용·투척이 실행됐다는 뜻이 아니며, 이 문서 작성 시점에 이번 실행의 자동 결과와 라이브 클라이언트 결과를 통과로 기록하지 않는다.

다음은 실제 클라이언트에서 아직 통과로 기록하지 않는다.

- 양조기 클릭 발전 과제와 바닐라 UI가 함께 열리는 실제 UX
- 주·보조 손 병과 모든 비용의 생존 모드 소비
- 실제 음용·투척·잔류 구름의 단계·시간·다중 효과
- 40개 효과 전체와 반대 효과 조합
- 손 교체, 빠른 연속 클릭, 인벤토리 경계, 로그아웃
- 두 플레이어 동시 사용과 실제 Realm 환경
