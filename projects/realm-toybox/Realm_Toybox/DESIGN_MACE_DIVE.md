# 철퇴 급강하 설계

상태: 조건부 설계, 미구현

## 목표

날개 결속 흉갑으로 활공하다 철퇴를 든 채 의도적으로 급강하하고, 명중 뒤 다시 이동 흐름을 이어간다. 플레이어 NBT 직접 수정, 강제 탑승, 반복 순간이동 떨림은 사용하지 않는다.

## 우선 UX

희망 입력은 아래를 6틱 유지하는 것이다.

- 날개 결속 흉갑 착용
- 활공 중
- 주 손에 철퇴
- 아래쪽 60도 이상 조준
- 웅크리기

정식 predicate에서 활공·웅크리기·시선 각도·장비 컴포넌트를 모두 안정적으로 판정할 수 있는지 G0에서 확인한다. 시선 각도를 직접 predicate로 표현할 수 없으면 `Rotation[0]` 같은 플레이어 NBT 의존 설계는 금지하고 전용 액티브 아이템으로 전환한다.

## 안정 대체 UX

`급강하 깃`을 보조 손에 들고 웅크리면 시작한다. 아이템은 사용 시 소비되지 않고 5초 cooldown만 가진다. 명시적 입력이라 오발과 상시 시선 검사가 줄어든다.

## 상태

- 준비 6틱
- 급강하 최대 30틱
- 재개방 잠금 20틱
- 명중 보상 창 10틱
- 전체 cooldown 100틱

급강하 시작 때 활공을 명령으로 안전하게 종료할 수 있는지 검증한다. 지원되지 않으면 활공 상태를 억지로 고치지 않고 아래 방향 바람 폭발 또는 짧은 하강 이동을 주는 대체 액티브로 축소한다.

명중은 철퇴의 post-attack 사건과 플레이어 급강하 상태를 함께 검사한다. 성공 시 작은 상향 바람 폭발, 1초 느린 낙하, 재활공 준비 피드백을 준다. 빗나가면 보호 효과 없이 정상 낙하 위험을 유지한다.

## 안전과 성능

- 상태 플레이어만 틱 검사
- 블록 아래 전역 스캔 금지
- 피해량은 바닐라 철퇴 낙하 공식에 맡김
- 추가 피해 없음
- 명중 보상은 한 급강하당 한 번
- 물·용암·차원 이동·사망·장비 교체 시 종료
- 무한 비행 방지를 위해 성공해도 cooldown 유지, 로켓 지급 없음

## G0 및 합격 기준

- 날개 흉갑의 glider 상태와 실제 활공 predicate 판정
- 웅크리기 연속 시간과 시선 판정
- 순수 명령으로 안전한 활공 종료 가능 여부
- 철퇴 명중 사건의 공격자 귀속
- 빗나감/명중 각각 낙하 피해와 재활공 흐름
- 2인 동시 급강하 상태 분리

활공 종료나 입력 판정이 불안정하면 자동 입력 방식은 폐기하고 `급강하 깃` 축소안만 구현한다.
