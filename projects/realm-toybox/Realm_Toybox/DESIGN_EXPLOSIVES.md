# 특수 폭약 설계

상태: 조건부 설계, 미구현

## 공통 안전 원칙

기본값은 블록 파괴 OFF, 화재 OFF다. 폭약은 이벤트 기반으로 작동하고 활성 폭약만 짧게 처리한다. 자연 TNT나 모든 아이템 엔티티를 검색하지 않는다. 관리자 설정과 팀/PvP 정책을 존중한다.

## A. 점착 폭탄

### UX

전용 아이템을 주 손에 들고 `/trigger tb_bomb set 1`을 실행하면 바라보는 8블록 이내 블록 면에 폭탄을 설치한다. 우클릭 감지 편법은 사용하지 않는다. 설치 전에 대상 면, 거리, 월드 경계, 활성 상한을 검사한다.

설치 후 60틱 퓨즈, 웅크리고 trigger 재입력 시 자신의 최근 폭탄 해체. 플레이어당 3개, 서버 전체 24개 상한.

### 구현

interaction/marker 한 쌍 또는 display+marker를 사용할 수 있으나 핵심 기능은 리소스팩 없이 입자와 소리로 이해 가능해야 한다. 폭탄은 소유자 ID, 생성 차원, 수명 점수를 가진다. 활성 폭탄 자체를 처리하는 방법이 전역 `@e` 틱 검색뿐이면 scheduled function + 제한된 전용 태그 검색 비용을 측정한다.

폭발은 `minecraft:explode`의 `block_interaction:none`, `create_fire:false`. 한 폭탄 한 번 플래그를 폭발 전에 기록한다.

## B. 채굴 폭약

### 목표

광석·상자·기계·건축 블록을 보존하고 자연 돌 계열만 작은 구형 패턴으로 제거한다.

### 허용 블록

전용 `toybox:mining_blast_breakable` 태그를 allowlist로 사용한다. 초기 목록은 stone, deepslate, tuff, granite, diorite, andesite와 각 자연 변종만 포함한다. 광석, 흙, 모래, 자갈, 목재, 유리, 컨테이너, 레드스톤, 기반암은 제외한다.

### 파괴 방식

바닐라 폭발에 맡기면 광석 보존을 보장할 수 없으므로 `block_interaction:none`으로 시각/넉백만 만들고, 사전에 정의한 반경 2의 최대 33개 좌표를 함수로 검사해 allowlist 블록만 `destroy` 또는 `setblock air` 처리한다.

`destroy`는 아이템 드롭과 행운/섬세한 손길 귀속 문제가 있으므로 기본은 드롭 없는 `setblock air`이다. 생존 자원 획득 도구가 아니라 굴착 장난감으로 명시한다. 드롭 지원은 발사자 도구 귀속을 공식적으로 보장할 수 있을 때만 별도 옵션으로 추가한다.

한 틱에 모두 처리하지 않고 3틱에 나눠 최대 11블록씩 변경한다. 작업 ID와 원래 중심 차원을 저장하며 청크가 언로드되면 취소한다.

## 비용

- 점착 폭탄: TNT + 슬라임볼 + 실 + 레드스톤
- 채굴 폭약: TNT + 철 곡괭이 + 종이 2 + 자수정

강력한 블록 변경 기능이므로 기본 제작 수량은 1개다.

## G0 및 합격 기준

- trigger 시선 raycast를 전역 엔티티 없이 구현
- 설치/해체 소유자 분리
- reload/재시작/청크 언로드 후 잔존 폭탄 정리
- 채굴 allowlist 외 블록 변경 0건
- 광석에 인접한 돌만 제거하고 광석 보존
- 동일 위치 동시 폭발과 작업 중 블록 변경 경쟁
- 24개 동시 퓨즈의 mspt 측정

allowlist 파괴의 원자성과 청크 안전을 보장하지 못하면 채굴 폭약은 출시하지 않는다.
