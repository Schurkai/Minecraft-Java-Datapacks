# 건축·이동 장난감 설계

상태: 도약·줄자·분필 v0.5.0-rc1 구현 / 점프 발판 v0.6.0-rc1 구현

## A. 점프 발판 — v0.6.0-rc1 구현

### UX

지정 블록 위에 올라서면 위로 튀어 오른다. 리소스팩 없이 식별 가능하도록 초기 블록은 `노란색 유광 테라코타 위 철 압력판` 구조로 고정한다.

데이터팩이 커스텀 블록을 등록할 수 없으므로 `노란색 유광 테라코타` 위에 바닐라 `철 중량 압력판`을 직접 놓는 두 블록 구조 자체가 발판 ID다. 별도 제작법·설치 trigger·전용 아이템은 없다. 드문 우연 배치도 발판으로 취급하는 대신 등록 좌표, marker, 강제 로드 청크를 없앴다.

### 구현

플레이어 발밑 블록 검사는 플레이어당 상수 비용이다. 지상이며 비행·활공·수중·탑승 중이 아니고 압력판 위 5블록이 공기 계열일 때 부양 IV 1초와 느린 낙하 3초를 적용한다. 플레이어 Motion 직접 수정과 착지 튕김인 `minecraft:bounciness`는 사용하지 않는다.

발동 또는 막힘 경고 뒤 플레이어별 래치를 1로 둔다. 공중에서는 래치를 유지하고 같은 발판에 착지해도 다시 발동하지 않으며, 일반 바닥에 착지하거나 두 블록 구조에서 벗어났을 때만 0으로 재무장한다. 발판 검색용 전역 marker·`@e`·예약 함수는 없고 압력판 레드스톤 동작은 그대로 유지한다.

### 합격 기준

- 공식 서버에서 두 블록 구조, 5칸 여유 공간 태그, 차폐 블록 거부, 스모크 뒤 블록/forceload 정리 통과
- 걷기/달리기/웅크리기/낙하 진입과 실제 상승 높이는 클라이언트 미검증
- 두 플레이어 동시 사용 미검증
- 천장 아래 비발동, 같은 발판 재착지 무한 반복 방지, 블록 일부 파손 뒤 재무장은 클라이언트 미검증

## B. 도약 장화 — RC4 구현

### UX와 수치

기존 `탄성`은 `minecraft:bounciness`를 높여 착지 뒤 튀게 했지만 점프키로 높이를 조절하는 기능이 아니었다. 표시명과 효과를 `도약 I–III`으로 바꾸되 기존 장비가 사라지지 않도록 내부 ID `toybox:springstep`은 유지한다.

- 도약 I 책: 슬라임 블록 + 토끼발 + 책 + 자수정
- 상승 중이며 점프키가 눌린 틱에만 `minecraft:apply_impulse`
- I/II/III 추가 추진량: 틱당 0.02/0.03/0.04
- 지상, 하강, 수중, 활공, 창작 비행, 탑승 중에는 발동하지 않음
- 키를 놓는 즉시 추가 추진 종료

별도 scoreboard나 전역 엔티티 검색은 없다. 누른 시간 자체를 저장하지 않고 26.2 플레이어 입력 predicate를 사용한다. 시선 상하각에 따른 수직 성분과 다른 상승 효과 중 발동은 수동 시험 항목이다.

## C. 줄자 — v0.5.0-rc1 구현

### UX

별도 전용 아이템과 제작법 없이 시작점에서 `/trigger tb_measure set 1`, 끝점에서 다시 실행하면 ΔX/ΔY/ΔZ, 직선거리, 맨해튼 거리를 채팅으로 표시한다. 명령 진입을 명확히 하고 가짜 커스텀 아이템의 복제·발동 판정 문제를 피한 안전 축소안이다. `/trigger tb_measure set 2`로 저장한 시작점을 취소한다.

시작 정수 블록 좌표와 차원은 플레이어별 scoreboard에 저장한다. 오버월드·네더·엔드만 지원하며 다른 차원이거나 저장 차원과 현재 차원이 다르면 계산을 거절하고 시작점은 유지한다. 최대 좌표 차이는 signed scoreboard 제곱 합 overflow 방지를 위해 축마다 26,000블록으로 제한한다.

직선거리는 `floor(sqrt(dx²+dy²+dz²))`이며 0..46,340의 16회 이진 탐색으로 계산한다. 맨해튼 거리는 `|dx|+|dy|+|dz|`다. 설계했던 입자 선은 원거리 청크와 입자 수 비용을 피하기 위해 구현하지 않았고 줄자는 틱 함수에서 계산하지 않는다.

## D. 분필 — v0.5.0-rc1 구현

리소스팩 없는 영구 커스텀 표식은 바닐라 블록을 바꿔야 하므로 위험하다. 1차 분필은 **임시 좌표 북마크**로 축소한다.

- 플레이어당 최대 8개 좌표
- `/trigger tb_chalk set 1..8`로 현재 정수 블록 좌표와 바닐라 차원을 해당 슬롯에 덮어써서 저장
- `/trigger tb_chshow set 1..8`로 선택한 표식을 요청자에게만 5초 동안 3점 `end_rod` 입자 기둥으로 표시
- 월드 블록/엔티티 영구 변경 없음
- 표시 중 차원 이동 시 즉시 중단하며 다른 차원의 표시는 시작하지 않음
- 재접속·`/reload`·재시작 후 scoreboard 좌표 유지, 팩 제거 시 무해

저장된 모든 슬롯을 한 번에 나열하거나 이름을 붙이는 UI는 v0.5에 없다. 슬롯 저장·표시 결과가 좌표와 차원을 채팅으로 알려 준다. 입자는 `force @s`로 요청자에게만 보내며, 청크를 강제 로드하거나 marker/interaction 엔티티와 예약 함수를 만들지 않는다. 임시 매크로 storage는 같은 함수 호출 안에서 만들고 즉시 제거한다.

## 공통 성능과 G0

- 점프 발판은 플레이어 발밑 상수 검사만 허용
- 줄자는 trigger 요청 시에만 계산
- 분필 저장·표시 시작은 trigger 요청 시에만 처리하고, 표시 중인 플레이어만 최대 100틱 동안 상수 개수 입자를 처리
- 좌표의 음수, 큰 값, 차원 ID 저장·출력 검증
- 매크로 scratch storage cleanup과 차원 이동 중단 검증
- 언어별 단위·문구는 translate 키 사용
