# Realm Toybox v0.9.0-rc1

Minecraft Java Edition 26.2 정식판(데이터팩 107.1)용 바닐라 플러스 장난감 상자입니다. 모드·플러그인·필수 리소스팩 없이 동작합니다.

## 언어

선택형 `Realm_Toybox_Resources`를 적용하면 게임 언어가 한국어(`ko_kr`)일 때 한국어, 그 외 언어에서는 영어로 표시됩니다. 리소스팩이 없어도 기능은 모두 동작하며 데이터팩의 영어 fallback이 보입니다.

## 설치

`Realm_Toybox_v0.9.0-rc1-java-26.2.zip`을 **압축 해제하지 않고** 월드의 `datapacks` 폴더에 넣습니다. Realm은 월드를 내려받아 팩을 넣은 뒤 다시 업로드하십시오. 접속 후 `/reload`, `/datapack list enabled`, `/trigger tb_help` 순서로 확인합니다.

한국어 이름과 안내가 필요하면 `Realm_Toybox_Resources_v0.9.0-rc1-java-26.2.zip`도 클라이언트 리소스팩으로 적용합니다.

## 기능

- 인챈트 상한: 보호 4종, 날카로움·강타·살충, 힘, 찌르기 X / 효율·밀도 VII / 내구성·행운·약탈 V / 격파 IV.
- 허용 조합: 보호 4종 상호 조합, 날카로움+강타+살충, 수선+무한, 다중 발사+관통. 섬세한 손길+행운과 급류+충성/집전 제한은 유지됩니다.
- 폭렬 I–III: 몹 또는 블록 적중 시 지형 파괴·화재 없는 폭발을 만듭니다. 지면 내부에 묻히던 폭발점을 위로 0.25블록 보정하고 폭발 피해를 켰습니다. 실제 반동 감각은 클라이언트 수동 시험 항목입니다. 폭렬은 다중 발사·관통 및 다른 특수 사격과 함께 붙지 않습니다.
- 균열 사격 I: **8–48블록 떨어진 블록에 맞는 순간 웅크리고 있을 때만** 몸이 들어갈 빈 도착 공간으로 이동합니다. 성공 시 2.5칸 피해, 3초 재사용 대기시간, 짧은 느린 낙하가 적용됩니다. 도착점 아래의 지지 바닥은 보장하지 않습니다.
- 도약 I–III: 장화를 신고 상승 중 점프키를 계속 누르면 매 틱 약한 추가 추진을 받아 더 높이 뜁니다. 일찍 놓으면 거의 일반 점프가 됩니다. 기존 장비 보존을 위해 내부 ID는 `toybox:springstep`을 유지합니다.
- 점프 발판(RC): 노란색 유광 테라코타 위에 철 중량 압력판을 놓고 밟으면 1초간 부양 IV와 3초간 느린 낙하가 적용됩니다. 위로 공기 5블록이 필요하며, 발판 위에 다시 떨어져도 반복 발동하지 않고 일반 바닥을 밟아야 재무장됩니다. 별도 트리거·전용 아이템·리소스팩은 필요 없습니다.
- 날개 결속 흉갑 7종: `crafting_transmute`로 입력 흉갑 컴포넌트를 보존하면서 `minecraft:glider`를 추가합니다.
- 바람 병: 짧은 공중 부양과 느린 낙하 효과를 줍니다.
- `/trigger tb_anvil set 1`: 자수정 조각 1개와 경험치 5레벨로 주 손 아이템의 `repair_cost`만 0으로 만듭니다.
- 갈고리(RC): 활 인챈트가 아니라 전용 낚싯대형 도구입니다. `낚싯대+끈+철사 덫 갈고리+슬라임볼+자수정 조각`으로 제작하고, 액체가 아닌 블록에 찌가 닿으면 그쪽으로 당깁니다. 물속 이동은 절반 속도이며 웅크리기·용암·사망·재접속·차원 이동 때 정리됩니다.
- 고등 마법부여(RC): 강화할 장비를 주 손, **같은 인챈트와 같은 현재 레벨 하나만 든 마법이 부여된 책**을 보조 손에 들고 마법부여대를 사용합니다. 조건이 맞으면 클릭 한 번으로 인챈트가 한 단계 오르며 책 1권, 경험치 `4+2×결과 레벨`, 청금석 `ceil(결과 레벨/2)`, VI 이상부터 자수정 `결과 레벨-5`개를 소비합니다.
- 포션 합성(RC): 일반·투척용·잔류형 포션을 양손에 한 병씩 들고 양조기를 사용합니다. 같은 단일 효과는 발광석 가루만 소지하면 단계 상승, 레드스톤만 소지하면 시간 연장으로 합성합니다. 서로 겹치지 않는 효과는 최대 5종까지 한 병으로 합칩니다. 효과는 최대 V, 지속시간은 최대 72,000틱(60분)입니다.
- 줄자(RC): `/trigger tb_measure set 1`로 시작점을 저장하고 끝점에서 다시 실행하면 ΔX/ΔY/ΔZ, 내림 직선거리, 맨해튼 거리와 **양 끝 블록을 포함한** X/Y/Z 크기, XZ 바닥 면적, 수직 4면 면적, 부피를 표시합니다. `/trigger tb_measure set 2`로 취소합니다. 같은 차원에서 축별 차이는 최대 26,000블록이며 32비트 점수 범위를 넘는 벽면적·부피만 안전하게 생략합니다.
- 분필 북마크(RC): `/trigger tb_chalk set 1..8`로 현재 블록 좌표를 슬롯에 저장하고 `/trigger tb_chshow set 1..8`로 자신에게만 5초간 입자 기둥을 표시합니다. 블록·청크를 강제 로드하거나 marker 엔티티를 만들지 않으며 저장 좌표는 재접속과 서버 재시작 뒤에도 유지됩니다.
- 분필 나침반(RC): 주 손에 **개조하지 않은 일반 나침반 정확히 1개**를 들고 자수정 조각 1개를 소지한 뒤 `/trigger tb_compass set 1..8`을 실행하면 해당 분필 좌표를 가리키는 비중첩 나침반으로 바뀝니다. 실제 자석석이나 강제 청크 로딩은 필요하지 않습니다. 다른 차원에서는 바닐라 나침반처럼 회전하며, 이미 각인했거나 사용자 지정한 나침반은 덮어쓰지 않습니다.
- 수프 냄비(RC): 불붙은 **일반 모닥불** 바로 위에 빈 가마솥을 놓고, 버섯 스튜·토끼 스튜·비트 수프 중 같은 종류 4개를 소지한 채 그 가마솥을 바라보고 `/trigger tb_soup set 1`을 실행합니다. 주 손을 비운 뒤 `set 2`로 한 그릇씩 꺼내며 총 4회분입니다. `set 3`은 남은 수프를 환불 없이 폐기합니다. 모닥불을 끄면 보관은 유지되지만 다시 피워야 꺼낼 수 있습니다.
- 수확 낫(RC): 제작대에서 `철 철 자수정 / 빈칸 막대 빈칸 / 빈칸 막대 빈칸`으로 만듭니다. 주 손이나 보조 손에 들고 5블록 안의 완숙 작물을 겨냥해 사용 키를 누르면 같은 높이의 3×3 영역에서 완숙 밀·당근·감자·비트·네더 사마귀만 수확합니다. 성공한 한 번에 내구도 1을 쓰며 자동 재파종은 하지 않습니다.

RC3 이하에서 만든 갈고리 책이나 갈고리 활은 자동 변환되지 않습니다. RC4 접속 시 새 갈고리 제작법이 해금되므로 전용 도구를 새로 제작하십시오.

### 고등 마법부여 책장과 비용

고등 마법부여는 바닐라 마법부여대 UI의 15책장 계산을 확장하지 않습니다. 클릭한 마법부여대를 중심으로 정의된 60개 슬롯만 세며, 책장과 테이블 사이의 전송 칸이 `#minecraft:enchantment_power_transmitter` 또는 `#minecraft:enchantment_power_provider`여야 활성으로 인정합니다.

- 결과 IV/V: 활성 책장 15개
- 결과 VI: 24개
- 결과 VII: 32개
- 결과 VIII: 40개
- 결과 IX: 48개
- 결과 X: 60개

60개 슬롯은 반경 2의 테이블 높이·한 칸 위 고리 32개, 반경 3의 테이블 높이 고리 24개, 반경 3 한 칸 위의 동서남북 4개입니다. 지원 인챈트는 보호·화염 보호·폭발 보호·발사체 보호, 날카로움·강타·살충, 힘·찌르기, 효율·밀도, 행운·약탈·내구성입니다. 각 인챈트의 Toybox 상한을 넘길 수 없으며 실패하면 아무것도 소비하지 않습니다.

### 포션 합성 규칙

- 같은 효과의 단계 상승: 두 입력의 단계가 같고 I–IV일 때만 결과가 한 단계 오릅니다. 지속시간은 짧은 쪽의 75%입니다. 결과 단계만큼의 발광석 가루(II=1, …, V=4)와 자수정 1개, 결과가 III 이상이면 자수정 1개를 더 씁니다.
- 같은 효과의 시간 연장: 두 입력의 단계 차가 1 이하일 때 낮은 단계로 맞추고 시간을 합산합니다. 레드스톤은 결과 15분마다 올림하여 1–4개를 씁니다.
- 서로 다른 효과 합치기: 양쪽 효과 ID가 하나도 겹치지 않아야 하며 결과는 최대 5종입니다. 자수정은 `결과 효과 수 + 입력의 III 이상 효과 수`개입니다.
- 병 형태가 다르면 일반 < 투척용 < 잔류형 중 높은 형태를 결과로 사용합니다. 일반에서 투척용으로 올라갈 때 화약 1개, 일반/투척용에서 잔류형으로 올라갈 때 드래곤의 숨결 1개가 필요합니다.
- 경험치 비용은 효과별 `S=(단계²)×max(1,floor(지속시간/1200))`의 합에 대해 `3+ceil(2×sqrt(S))` 레벨입니다. 즉시 효과의 지속시간은 1틱으로 취급합니다.

지원하는 40개 바닐라 효과 ID만 받습니다. 입력에 숨은 연쇄 효과, 중복 효과, VI 이상, 72,000틱 초과, 알 수 없는 효과가 있으면 거부합니다. 결과는 고정 보라색의 새 `혼합 물약`이므로 입력 병의 사용자 이름·설명·기타 비효과 컴포넌트는 보존하지 않습니다.

## 안전과 호환성

바닐라 `exclusive_set` 태그 전체를 덮어쓰지 않습니다. 빈 커스텀 배타 태그도 제거하고, 필요한 관계만 좁은 전용 태그로 정의했습니다. 틱 진입점은 플레이어만 확인하며, 폭렬·균열 사격은 사건 기반, 갈고리 찌 검색은 활성 플레이어에게만 최대 32블록 범위로 수행합니다. 수확 낫은 `using_item` 사건으로 시작하고 최대 25회의 0.2블록 시선 추적과 9칸 검사만 수행하며, 틱에서는 최대 10틱 동안 활성 사용자 태그만 재무장합니다. 고등 마법부여와 포션 합성도 각각 마법부여대·양조기 사용 발전 과제에서만 실행되고 틱 함수에서는 검색하지 않습니다. 줄자와 분필 나침반은 trigger 때만 계산·교체하고, 나침반은 `tracked:false` 고정 좌표라 목표 청크를 불러오지 않습니다. 분필은 표시를 요청한 플레이어만 최대 100틱 처리합니다. 점프 발판은 플레이어별 발밑 두 블록만 확인합니다. 수프 냄비 marker는 트리거 시 바라보는 가마솥의 0.9블록 안에서만 찾고, 서버 전체 상한 64개를 5분마다 한 번씩 파손 정리합니다. 수프 marker를 매 틱 전역 검색하지 않습니다.

26.2 `crafting_transmute`는 같은 결과가 되는 일반 재결속을 레시피 단계에서 거부합니다. 다만 날개 결속 다이아몬드 흉갑을 네더라이트로 업그레이드한 뒤 네더라이트 결속 레시피에 다시 넣는 경계 사례는 실제 UI 검증 전이므로 피하십시오.

## 개발 검증

PowerShell 5.1 기준 순서입니다.

```powershell
node tools\validate.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File tools\package.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools\test_server.ps1 `
  -ServerJar ..\server-26.2.jar `
  -PackArtifact ..\release\Realm_Toybox_v0.9.0-rc1-java-26.2.zip
```

리소스팩은 `powershell -NoProfile -ExecutionPolicy Bypass -File ..\Realm_Toybox_Resources\package.ps1`로 패키징합니다. 장시간 프로세스의 식별·PID·잠금·정리 규칙은 `PROCESS_SAFETY.md`를 따릅니다.

실제 클라이언트의 고등 마법부여·포션 시험은 빈 인벤토리와 일회용 월드에서 [`CLIENT_TEST.md`](CLIENT_TEST.md), 점프 발판·줄자·분필·분필 나침반 시험은 [`BUILDING_TEST.md`](BUILDING_TEST.md), 수프 냄비 시험은 [`SOUP_TEST.md`](SOUP_TEST.md), 수확 낫 시험은 [`SICKLE_TEST.md`](SICKLE_TEST.md)를 따르십시오. 시험 절차나 키트를 제공하는 것 자체는 시험 통과를 뜻하지 않습니다.

실제 클라이언트에서 아직 끝내지 않은 항목은 `KNOWN_LIMITATIONS.md`, 실행한 검증만 `TEST_REPORT.md`에 기록했습니다. 팩 제거 전에는 월드를 백업하고 커스텀 인챈트 장비를 일반 장비로 교체하십시오.
