# 변경 기록

## v0.1.0-rc1 — 2026-08-27

- 블록 접촉 감지와 실제 자동 견인 이동 추가
- 거리별 3단계 속도와 물속 절반 속도 추가
- 발·몸·머리 높이 네 모서리를 검사하는 충돌 표본 이동 추가
- 한 번에 이동이 막히면 절반 거리 재시도, 연속 4틱 막힘 해제 추가
- 30블록 사거리, 60틱 활성 제한, 사용 후 재사용 대기시간 추가
- 웅크리기·재사용·관전자·겉날개 비행·탑승·용암·찌 손실 정리 추가
- 느린 낙하 안전 보조와 완료·실패·막힘 피드백 추가
- 이동 함수 자동 생성, 정적 검증, 공식 서버 시험, 패키징 스크립트 갱신
- 사용법·감사·시험 계획·제한 사항 문서를 RC 기준으로 갱신

## v0.0.1-p0 — 2026-08-22

- 독립 `grapple` 네임스페이스와 Java 26.2 / 데이터팩 형식 107.1 메타데이터 추가
- 전용 낚싯대형 갈고리와 제작법 추가
- `minecraft.used:minecraft.fishing_rod` 기반 사용 감지 추가
- 반경 5블록, 최대 3틱의 새 찌 검색 추가
- `execute on origin` 기반 소유자 확인과 증가형 연결 ID 추가
- 두 번째 우클릭·웅크리기·찌 손실·시간 초과 정리 추가
- 일반 낚싯대 제외와 기존 사용 통계 초기 스냅샷 추가
- P0 시험 메시지와 한국어 도움말 추가
- 실험적 인챈트 레지스트리 제거 원칙 적용
