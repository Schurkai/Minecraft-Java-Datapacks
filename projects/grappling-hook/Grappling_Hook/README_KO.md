# 갈고리

`Grappling_Hook v0.1.0-rc1`은 Minecraft Java Edition 정식 26.2용 순수 데이터팩이다.

낚싯대형 전용 갈고리를 블록에 걸면 플레이어를 고정점 쪽으로 자동 견인한다. Fabric·Forge·Paper·플러그인·실험적 기능이 필요 없으며 리소스팩 없이 작동한다.

RC는 실제 클라이언트 조작감과 2인 동시 사용을 검증하기 위한 배포 후보이며 정식판이 아니다.

## 설치

1. 월드를 백업한다.
2. `Grappling_Hook_v0.1.0-rc1-java-26.2.zip`을 월드의 `datapacks` 폴더에 넣는다.
3. 이전 갈고리 P0 ZIP은 제거한다.
4. `/reload`를 실행한다.
5. `/datapack list enabled`와 `/function grapple:help`로 확인한다.

Realm에서는 ZIP을 넣은 로컬 월드를 업로드한다. 이 팩은 동적 인챈트·차원·피해 유형 레지스트리나 feature flag를 포함하지 않는다.

## 제작법

```text
실  철사 덫 갈고리  실
철괴    낚싯대      철괴
빈칸    돌풍구      빈칸
```

첫 접속 때 제작법이 자동 해금된다. 실제 기반 아이템은 낚싯대지만 `custom_data`로 일반 낚싯대와 구분하고 기본 철사 덫 갈고리 모델을 표시한다.

## 사용법

1. 갈고리를 **주 손**에 든다.
2. 최대 30블록 안의 액체가 아닌 블록을 향해 우클릭한다.
3. 찌가 블록에 닿으면 그쪽으로 자동 견인된다.
4. 다시 우클릭하거나 웅크리면 해제된다.
5. 고정점에서 2.25블록 이내에 도착하면 자동 종료된다.

다음 상황에서는 안전하게 정리된다.

- 물이나 용암에 찌가 들어감
- 플레이어가 용암에 닿음
- 경로가 4틱 연속 막힘
- 30블록 이탈 또는 시간 초과
- 찌 손실, 사망, 재접속, 차원 이동
- 관전자, 창작 비행, 겉날개 비행, 탈것 탑승

## 속도와 대기시간

| 고정점 거리 | 공중 속도 | 물속 속도 |
|---|---:|---:|
| 16블록 초과 | 틱당 0.75블록 | 틱당 0.375블록 |
| 8~16블록 | 틱당 0.60블록 | 틱당 0.30블록 |
| 2.25~8블록 | 틱당 0.40블록 | 틱당 0.20블록 |

- 찌 비행 대기: 최대 3초
- 견인: 최대 3초
- 성공·수동 해제·경로 막힘 뒤 대기시간: 1.5초
- 빗맞힘·찌 손실 뒤 대기시간: 0.5초
- 견인 중 느린 낙하, 정상 도착 뒤 1초간 느린 낙하

각 보폭은 발·허리·머리 높이 네 모서리, 총 12점을 검사한다. 전체 보폭이 막히면 절반 보폭을 다시 시험하고, 4틱 연속 실패할 때만 끊는다.

## 성능과 멀티플레이

- 일반 플레이어는 낚싯대 사용 통계 변화와 cooldown만 확인한다.
- 새로 던진 사용자는 최대 3틱 동안 반경 5블록의 찌만 찾는다.
- `execute on origin`으로 찌의 실제 소유자를 확인한다.
- 활성 사용자만 반경 30블록에서 자기 연결 ID의 찌를 찾는다.
- 전역 엔티티 매 틱 검색, 청크 강제 로드, 상주 marker가 없다.

내부 네임스페이스는 `grapple`이므로 `Enchant_Plus`와 함께 설치할 수 있다.

## 언어와 리소스팩

리소스팩 없이도 모든 기능이 작동하고 한국어 fallback을 표시한다. 한국어 클라이언트만 한국어, 그 밖의 언어는 영어로 자동 구분하려면 추후 선택 리소스팩이 필요하다.

## RC 수동 시험

벽·바닥·천장, 물, 울타리·문·반 블록, 29/31블록, 재우클릭·웅크리기, 사망·재접속·차원 이동을 시험한다. 두 명이 같은 위치에서 동시에 던졌을 때 상대 찌를 가져오면 실패다.

실행 결과는 `TEST_REPORT.md`에만 기록하며, 실행하지 않은 시험은 통과로 간주하지 않는다.
