# 갈고리 v0.1.0-rc1 시험 계획

## 자동 정적 검증

- JSON과 `pack.mcmeta` 전체 파싱
- 데이터팩 형식 107.1과 feature flag 부재
- 내부 함수 참조와 틱 호출 그래프 해석
- 동적 인챈트·차원·피해 유형·월드 생성 레지스트리 부재
- 모든 `@e` 선택자의 거리 제한
- 사용 통계, 주 손 custom data, `execute on origin` 소유자 검사
- 이동 함수 12개와 함수당 몸체 표본 12개
- 최대 30블록, 용암 통과 금지, 고정 틱 중복 이동 방지
- ZIP 루트, 경로 구분자와 SHA-256

## 공식 서버 자동 시험

- 공식 26.2 서버 JAR SHA-1 확인
- 소스 디렉터리 최초 로드·`/reload`·저장·종료·재시작
- 릴리스 ZIP 최초 로드·`/reload`·저장·종료·재시작
- 프로브 점수와 활성 데이터팩 목록
- JSON, 태그, predicate, 함수, 명령, 레지스트리 오류 검색
- 종료 뒤 식별 가능한 Java 프로세스·PID 파일·lock·포트 잔존 확인

## 실제 클라이언트

- 제작법 해금, 이름·설명·기본 모델, 낚싯줄
- 바닥·벽·천장 고정과 허공 빗맞힘
- 거리 5·8·16·29·31블록
- 세 속도 구간과 물속 절반 속도
- 2.25블록 도착, 3초 시간 초과, 재사용 대기시간
- 재우클릭·웅크리기 해제
- 느린 낙하 적용과 중간 해제 추락 위험
- 용암, 찌 입수, 플레이어 입수
- 반 블록·계단·울타리·벽·문·꽃·덩굴·낮은 천장
- 경로 절반 보폭 재시도와 4틱 막힘 종료
- 손 교체, 관전자, 창작 비행, 겉날개, 탈것
- 사망·로그아웃·재접속·차원 이동
- 일반 낚싯대 무반응
