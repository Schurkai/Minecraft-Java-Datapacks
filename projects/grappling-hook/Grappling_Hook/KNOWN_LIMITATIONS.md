# 알려진 제한 사항

- 순수 데이터팩은 플레이어의 속도 벡터를 안정적으로 직접 설정할 수 없어 작은 텔레포트를 반복한다. 원작 감자 갈고리의 진자·장력 물리를 재현하지 않는다.
- 실제 우클릭, 줄 렌더링, 이동감, 2인 동시 사용과 Realm 업로드는 아직 수동 검증 전이다.
- 갈고리는 주 손에서만 감지한다. 낚싯대 사용 통계만으로 실제 사용 손을 구분할 수 없기 때문이다.
- 새 아이템 ID를 추가할 수 없어 실제 아이템은 `minecraft:fishing_rod`다.
- 꽃과 잔디는 통과 대상으로 처리하지만 반 블록·계단·문·울타리 같은 복잡한 충돌 모양은 표본 판정이 실제 모양과 다를 수 있다.
- 웅크리기·재우클릭으로 중간 해제하면 도착 후 낙하 보호를 받지 않는다. 높은 곳에서 해제하면 정상적인 추락 위험이 있다.
- 겉날개 비행, 창작 비행과 탈것 탑승 중에는 작동하지 않는다.
- 찌가 물이나 용암에 들어가면 실패한다. 플레이어가 물에 들어가면 절반 속도로 계속 견인된다.
- 오버월드·네더·엔드 밖의 커스텀 차원 정리는 보장하지 않는다.
- 리소스팩이 없으면 클라이언트 언어와 관계없이 한국어 fallback이 표시된다.
- 팩을 제거해도 scoreboard objective와 저장된 플레이어 태그는 남지만 팩이 없으면 실행되지 않는다.
- 공식 서버 자동 시험은 JSON·태그·predicate·함수·명령 로드만 증명하며 실제 플레이어 이동 물리는 증명하지 않는다.
