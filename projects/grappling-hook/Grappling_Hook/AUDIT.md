# 갈고리 v0.1.0-rc1 감사

## 대상

- Minecraft Java Edition 정식 26.2
- 데이터팩 형식 107.1
- 공식 서버 JAR SHA-1: `823e2250d24b3ddac457a60c92a6a941943fcd6a`
- 순수 데이터팩, 핵심 기능용 리소스팩·모드·플러그인 없음

## 기존 시제품에서 확인한 문제

- `Realm_Toybox` 시제품은 `toybox:grappling` 커스텀 인챈트의 `minecraft:projectile_spawned` 효과에 의존했다.
- 동적 인챈트 레지스트리는 Realm 안전 배포 원칙과 맞지 않는다.
- 기존 자동 견인은 실제 클라이언트 조작감과 2인 소유자 교차를 수동 검증하지 못했다.
- 기존 팩의 다른 기능과 같은 `toybox` 네임스페이스를 사용해 독립 배포에 적합하지 않았다.

## P0에서 검증한 기반

- 별도 `grapple` 네임스페이스를 사용한다.
- 커스텀 인챈트와 모든 동적 레지스트리 항목을 제거했다.
- 바닐라 낚싯대 사용 통계가 증가한 플레이어만 최대 3틱 동안 반경 5블록의 새 찌를 찾는다.
- 후보 찌는 `execute on origin`으로 현재 사용자 소유인지 확인한 뒤에만 태그와 연결 ID를 받는다.
- 첫 설치 때 기존 낚싯대 사용 통계를 복사하므로 과거 통계가 가짜 발사로 처리되지 않는다.

## RC1 구현과 안전성 감사

- 연결된 찌가 땅에 닿거나 상하좌우 0.16블록 표본에서 비통과 블록을 만나면 당김 상태로 전환한다.
- 플레이어와 갈고리 사이 거리에 따라 매 틱 0.40, 0.60, 0.75블록을 이동하며 물속에서는 절반 속도를 사용한다.
- 각 이동 함수는 발·몸·머리 높이의 네 모서리, 총 12개 표본을 검사한다. 한 번에 이동할 수 없으면 절반 거리만 다시 검사하고, 연속 4틱 막히면 안전 해제한다.
- 최대 탐색 거리는 30블록이고 활성 시간은 최대 60틱이다.
- 재사용, 웅크리기, 관전자 모드, 겉날개 비행, 탑승, 용암, 찌 손실, 시간 초과 때 상태와 찌를 정리한다.
- 성공·수동 해제 뒤 30틱, 실패 뒤 10틱의 재사용 대기시간을 둔다. 대기시간 중 새로 생긴 자기 찌만 소유자 확인 후 제거한다.
- 활성 사용자에게만 짧은 느린 낙하 효과를 주며 영구 속성이나 전역 상태를 수정하지 않는다.
- 틱 진입점과 모든 엔티티 선택자는 거리 제한 또는 현재 실행 문맥을 사용한다. 범위 없는 전역 `@e` 검색은 없다.
- 이동은 속도 벡터가 아닌 충돌 표본 검사 후 순간이동이므로 진자 물리와 완전히 같지는 않다.

## 실행한 자동 정적 검증

2026-08-27에 다음을 실제 실행했다.

- JSON·메타데이터 8개와 함수 40개 파싱·구문 검증 통과
- 내부 함수 참조 37개 해석 통과
- 충돌 이동 함수 12개 생성 및 도달 가능성 확인
- 각 이동 함수의 12개 충돌 표본과 현재 플레이어만 대상으로 하는 순간이동 확인
- 런타임 데이터의 동적 레지스트리, `toybox:grappling`, P0 진단 문구 부재 확인
- 모든 `@e` 선택자의 거리 제한 확인

공식 서버의 소스 및 최종 ZIP 시험 결과와 SHA-256은 `TEST_REPORT.md`에 기록한다.

## 아직 증명하지 않은 항목

- 실제 우클릭 직후 통계 증가와 찌 생성의 틱 순서 및 체감 지연

- 같은 위치의 2인이 동시에 던졌을 때 소유자 연결이 교차하지 않는지
- 실제 지형에서 모서리·문·덫문·울타리·비정형 블록 충돌의 체감
- 두 번째 우클릭과 웅크리기 해제 UX, 낙하 위험, 물속 절반 속도의 체감
- Realm 업로드·재접속·다인 장시간 운용
